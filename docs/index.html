TurboWarp HTML

TurboWarp HTML builds HTML as immutable structured fragments. Blocks create escaped text, elements, attributes, and sibling sequences; the final HTML string is produced only by an explicit render block.

Core Flow

text [Server status]
h1 [text result]
body [h1 result]
html [body result]
render HTML [html result]

Safety Model

  • Text node content is escaped by default.
  • Attribute values are quoted and escaped.
  • Event-handler attributes such as onclick are rejected.
  • Executable URL schemes such as javascript: are rejected for link and image URLs.
  • No raw HTML injection block is provided.
  • Educational CSS is supported with style [CSS]; JavaScript remains unsupported.

HTTP Server Interoperability

For turbowarp-http-server, pass the rendered string as the response body and set Content-Type: text/html; charset=utf-8. The HTTP server does not need to depend on this package.

Educational CSS

Use class attributes on elements and define those classes with style [CSS] in head. CSS is useful for teaching presentation and layout, but it can also visually hide or imitate UI, so load projects only from trusted sources.

TypeScript API

The package also exports block-free builder functions from @kubohiroya/turbowarp-html, including text, element, common element factories, withAttribute, concat, render, renderWithValidation, and validate.
